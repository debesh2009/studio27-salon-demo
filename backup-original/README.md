# STUDIO 27 — Salon Website Demo
Responsive static website made with HTML, CSS and vanilla JavaScript. No build tools required.

## Run in VS Code
1. Download and extract this ZIP.
2. Open the `studio27-salon-demo` folder in VS Code.
3. Install the **Live Server** extension (Ritwick Dey) if needed.
4. Right-click `index.html` → **Open with Live Server**. You can also open `index.html` directly in a browser.

## Before showing to a real salon
- This is a fictional concept demo. Do not present it as an existing salon's real website.
- Confirm and replace demo prices, address, hours, services and contact details with the salon.
- Replace stock photos with salon photos only with permission.
- In `script.js`, replace `919999999999` with the salon's WhatsApp number in international format, digits only.
- The form opens WhatsApp; it does not save appointments or confirm bookings.
- Google Fonts and Unsplash images require internet access.

## Files
- `index.html` — content and sections
- `styles.css` — design and responsive layout
- `script.js` — navigation and WhatsApp appointment request
